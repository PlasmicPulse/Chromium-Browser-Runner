- [API build ordering](api-build-ordering.md) — The API dev workflow cleans and rebuilds its output at startup; never overlap it with a standalone build.
- [Playwright deployment packaging](playwright-deployment.md) — Chromium must be installed and launched from a deployment-included path, not the excluded workspace cache.
- [Remote browser responsiveness](remote-input-latency.md) — Screenshot capture must not block ordered input; drop stale visual work rather than accumulating latency.
- [Browser display requirements](display-requirements.md) — Fit width with scrolling, in-page maximization rather than native fullscreen, and a normal mouse cursor.
- [Auth provisioning](auth-provisioning.md) — Managed Clerk rejects archive-style project titles ending in .zip; rename the project before provisioning.
- [Shared proxy rate limits](shared-proxy-limits.md) — Express req.ip may identify the shared proxy, so IP-only cooldowns can throttle unrelated visitors together.
- [Chat identity](chat-identity.md) — Display names are unverified and may collide; matching names do not establish sender identity or message ownership.
- [PostgreSQL pagination](postgres-pagination.md) — Preserve timestamp microseconds in cursors; explicitly type query rows to avoid cursor-inference and overload traps.
- [Pet parking](pet-parking.md) — Parking is independent of care/rest; movable beds must remain reachable and dock correctly near screen edges.
- [Consent-gated verification](consent-gated-verification.md) — A preview capture of the consent screen does not verify interactions behind it.
- [Pip play constraints](pip-play.md) — Rough play is figurative, never destructive or a happiness penalty; avoid comic sound-effect text and protect browser responsiveness.
- [Background photo storage](background-photo-storage.md) — Background photos must stay in the visitor's current browser, without cloud uploads or cross-device sync.
- [Local music storage](local-music-storage.md) — Uploaded music is MP3-only and stays in the visitor's browser; don't add streaming links or remote storage.
