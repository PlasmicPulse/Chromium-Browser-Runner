---
name: Background photo storage
description: User-selected persistence scope for personal new-tab background photos.
---

Background photos are saved in this browser only, not uploaded to a server or synchronized across devices.

**Why:** The user explicitly chose “This browser only” when offered browser-only storage versus cross-device sign-in and cloud storage.

**How to apply:** Preserve local, private browser storage when changing background customization. Do not introduce visitor accounts, server uploads, or cloud-storage charges for background photos without asking the user.
